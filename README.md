# Python Fundamentals Capstone Project

## Project Overview

This project is a Python fundamentals capstone focused on data manipulation and analysis using Pandas and NumPy.

The project works with Project, Employee, and Seniority Level datasets and performs a series of data preparation, transformation, filtering, aggregation, and analysis tasks.

## Technologies Used

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Project Tasks

The notebook covers Tasks 1–10, including:

- Creating Pandas DataFrames
- Saving and loading datasets as CSV files
- Handling missing values
- Data filtering and transformation
- Merging datasets
- Grouping and aggregation
- Sorting and analysis
- Working with employee, project, and seniority-level data
